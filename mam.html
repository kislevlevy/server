THE SHORT VERSION · WINDOWS

Connect qBittorrent to MAM.

Browser → home IP. qBittorrent + curl → same VPN IP.

0 of 6 steps complete
STEP 1 OF 6

Get MAM approval

Ask MAM staff to approve NordVPN + Dynamic Seedbox. Already approved? Continue.

STEP 2 OF 6

Put both apps on the VPN

Pause torrents. In NordVPN → Settings → Split tunneling, choose Enable VPN for selected apps and add:

  • qBittorrent — select its actual executable.
  • curl — C:\Windows\System32\curl.exe

Reconnect NordVPN and restart qBittorrent. Your browser can stay on your home connection.

Different mode label? / Protect against VPN drops

If the list means “exclude from VPN,” keep qBittorrent and curl out of it. Remove any separate qBittorrent proxy for this setup.

In qBittorrent → Tools → Options → Advanced → Network interface, select the active NordVPN adapter. Verify it with your VPN protocol; do not guess the adapter name. Test that a legal public test torrent stops when the VPN disconnects, with MAM torrents paused. Check IPv6 too: the curl commands below test IPv4 only.

STEP 3 OF 6

Check the IP

Open Windows PowerShell. Copy, paste, and run:

PowerShell
& "$env:SystemRoot\System32\curl.exe" -q -4 --noproxy "*" --fail --silent --show-error --connect-timeout 15 --max-time 30 https://api.ipify.org

Must show the VPN IP, not your home IP. Also confirm qBittorrent’s tracker IP matches through MAM’s diagnostic or staff. curl alone does not prove qBittorrent’s route.

It shows my home IP

Stop. Check the split-tunnel mode and the exact curl executable, then reconnect NordVPN and reopen PowerShell. If it still fails, restart Windows or contact NordVPN support. Do not register the home IP.

STEP 4 OF 6

Get your MAM session cookie

Open MAM → Preferences → Security. Create a dedicated session and enable Allow session to set Dynamic Seedbox IP. Follow the current form’s IP instructions.

Copy the mam_id value only. Keep it private; it is not your torrent passkey.

STEP 5 OF 6

Run the update

Click Copy command, paste into PowerShell, and run. Enter the verified qBittorrent VPN IPv4, type YES to confirm, then paste your cookie at the hidden prompt.

PowerShell · setup + future updates
Show command (optional)
& {
    $ErrorActionPreference = 'Stop'
    $curl = "$env:SystemRoot\System32\curl.exe"
    $endpoint = 'https://t.myanonamouse.net/json/dynamicSeedbox.php'
    $dir = Join-Path $env:LOCALAPPDATA 'MAM-Seedbox'
    $jar = Join-Path $dir 'mam.cookies'
    $common = @('-q', '-4', '--noproxy', '*', '--fail', '--silent',
        '--show-error', '--connect-timeout', '15', '--max-time', '30')

    $expected = (Read-Host 'Enter the independently verified qBittorrent VPN IPv4').Trim()
    $parsed = $null
    if (-not [Net.IPAddress]::TryParse($expected, [ref]$parsed) -or
        $parsed.AddressFamily -ne [Net.Sockets.AddressFamily]::InterNetwork) {
        throw 'Enter a valid public IPv4 address, not an adapter address.'
    }
    $actual = & $curl @common 'https://api.ipify.org'
    if ($LASTEXITCODE -ne 0) { throw 'IP check failed. No update sent.' }
    if (("$actual").Trim() -ne $expected) {
        throw "IP mismatch: curl uses $actual. No update sent. Fix routing first."
    }
    if ((Read-Host 'NordVPN connected, route verified, and MAM VPN approval obtained? Type YES') -cne 'YES') {
        throw 'Stopped. No update sent.'
    }
    New-Item -ItemType Directory -Path $dir -Force | Out-Null
    # Restrict this dedicated folder to your Windows account.
    $sid = [Security.Principal.WindowsIdentity]::GetCurrent().User.Value
    & "$env:SystemRoot\System32\icacls.exe" $dir /inheritance:r /grant:r "*${sid}:(OI)(CI)F" | Out-Null
    if ($LASTEXITCODE -ne 0) { throw 'Could not protect cookie folder.' }

    $requestArgs = @($common | Where-Object { $_ -ne '--fail' })
    $requestArgs += @('--write-out', "`nMAM_HTTP_STATUS:%{http_code}")
    $hasCookie = (Test-Path -LiteralPath $jar) -and
        (Select-String -LiteralPath $jar -Pattern "`tmam_id`t[^\s]+" -Quiet)
    if ($hasCookie) {
        $raw = & $curl @requestArgs --cookie $jar --cookie-jar $jar $endpoint
        $exitCode = $LASTEXITCODE
    } else {
        $secret = Read-Host 'Paste ONLY the mam_id value (hidden), then Enter' -AsSecureString
        $ptr = [IntPtr]::Zero
        $token = $null
        try {
            $ptr = [Runtime.InteropServices.Marshal]::SecureStringToBSTR($secret)
            $token = [Runtime.InteropServices.Marshal]::PtrToStringBSTR($ptr)
            if ($token -cnotmatch '^[A-Za-z0-9%._~+/=-]+$') {
                throw 'Unexpected cookie characters. Use only its value; do not add quotes or mam_id=.'
            }
            # Feed the secret through stdin, not the process command line.
            $raw = ('cookie = "mam_id=' + $token + '"') |
                & $curl @requestArgs --config - --cookie-jar $jar $endpoint
            $exitCode = $LASTEXITCODE
        } finally {
            if ($ptr -ne [IntPtr]::Zero) {
                [Runtime.InteropServices.Marshal]::ZeroFreeBSTR($ptr)
            }
            $token = $null
            $secret.Dispose()
        }
    }
    if ($exitCode -ne 0) { throw "Network request failed (curl exit $exitCode). Read the curl error above." }
    $responseText = $raw -join "`n"
    if ($responseText -notmatch '(?s)^(.*)\r?\nMAM_HTTP_STATUS:(\d{3})$') {
        throw 'Could not read HTTP status. Do not assume MAM updated.'
    }
    $body = $Matches[1]
    $httpStatus = [int]$Matches[2]
    if ($httpStatus -lt 200 -or $httpStatus -ge 300) {
        Write-Host "HTTP $httpStatus - server response (review privately):"
        Write-Host $body.Substring(0, [Math]::Min(3000, $body.Length))
        throw 'MAM did not confirm an update. Share only the short error text, never cookies or passkeys.'
    }
    try { $result = $body | ConvertFrom-Json }
    catch { throw 'Non-JSON response. Stop and check MAM service status/support.' }
    if ($result.Success -ne $true) {
        Write-Host ($raw -join "`n")
        throw 'MAM did not confirm success. Read the troubleshooting section.'
    }
    Write-Host 'MAM confirmed Success=true. Now verify the torrent tracker in qBittorrent.'
    if (-not (Test-Path -LiteralPath $jar) -or
        -not (Select-String -LiteralPath $jar -Pattern "`tmam_id`t" -Quiet)) {
        Write-Warning 'No reusable mam_id cookie found. Check session setup before the next update.'
    }
}

Look for “MAM confirmed Success=true.” The cookie is saved privately on this PC for later updates. Never share it.

STEP 6 OF 6

Check qBittorrent

Select a MAM torrent → Trackers. Wait for its next announce. The tracker should work without “Unrecognized host/PassKey.”

VPN IP changed? Recheck step 3, then rerun step 5 before resuming MAM torrents.

Still stuck? Sources & privacy notes

HTTP 403: the server refused the request. Read the response now printed by step 5. A session error calls for checking your dedicated session and its permission; an HTML access-denied/security page calls for MAM staff to review the VPN IP. Do not repeatedly retry or change IPs to bypass a block.

Invalid session / Invalid Cookie / Incorrect session type: create a fresh dedicated MAM session with Dynamic Seedbox permission, then remove the saved cookie below. Rerun step 5 and paste only the new mam_id value at the hidden prompt.

PowerShell · remove the saved cookie
Remove-Item -LiteralPath "$env:LOCALAPPDATA\MAM-Seedbox\mam.cookies" -Confirm

This asks before deleting the local cookie. It does not revoke the session on MAM.

Last change too recent: wait for MAM’s allowed interval; do not repeatedly retry.

Success but tracker rejects: ask MAM staff to check your diagnostic and tracker IP. Keep cookies, passkeys, and full tracker URLs out of screenshots.

The saved cookie is plaintext under %LOCALAPPDATA%\MAM-Seedbox\mam.cookies, in a folder restricted to your account. Administrators and software running as you can still read it. Clear clipboard history after pasting. Revoke a leaked session in MAM.
